# Vim 常用文本选择快捷键

## 1. 进入可视模式

| 按键 | 说明 |
| --- | --- |
| `v` | 字符可视模式（按字符选择） |
| `V` | 行可视模式（整行选择） |
| `Ctrl-v` | 块可视模式（矩形列选择） |
| `gv` | 重新选中上一次的选区 |
| `o` | 在选区两端之间切换光标（扩展另一头） |
| `O` | 块模式下切换到同行另一角 |
| `Esc` / `Ctrl-[` | 退出可视模式 |

## 2. 在可视模式中扩展选区

可视模式下，所有移动命令都会扩展选区：

| 按键 | 说明 |
| --- | --- |
| `h` `j` `k` `l` | 左 / 下 / 上 / 右 |
| `w` / `b` / `e` | 下一个词首 / 上一个词首 / 词尾 |
| `W` / `B` / `E` | 同上，按空白分隔的“大词” |
| `0` / `^` / `$` | 行首 / 首个非空字符 / 行尾 |
| `gg` / `G` | 文件开头 / 文件末尾 |
| `{` / `}` | 上一段 / 下一段 |
| `%` | 跳到匹配的括号 |
| `f{c}` / `t{c}` | 到行内字符 `c` / `c` 之前 |
| `/pattern` | 扩展到搜索匹配处 |
| `5j` | 带计数：向下扩展 5 行 |

## 3. 文本对象（最常用）

格式：`v` + `i`（inner，不含边界）或 `a`（around，含边界）+ 对象。
也可以直接配合操作符使用，如 `diw`、`ci"`、`ya(`，无需先进入可视模式。

| 按键 | 选中内容 |
| --- | --- |
| `viw` / `vaw` | 当前单词 / 单词及后面的空格 |
| `viW` / `vaW` | 当前“大词”（含标点） |
| `vis` / `vas` | 当前句子 |
| `vip` / `vap` | 当前段落 / 段落及后面的空行 |
| `vi"` / `va"` | 双引号内 / 含双引号 |
| `vi'` / `va'` | 单引号内 / 含单引号 |
| ``vi` `` / ``va` `` | 反引号内 / 含反引号 |
| `vi(` / `va(` | 圆括号内 / 含括号（同 `vib` / `vab`） |
| `vi{` / `va{` | 花括号内 / 含括号（同 `viB` / `vaB`） |
| `vi[` / `va[` | 方括号内 / 含括号 |
| `vi<` / `va<` | 尖括号内 / 含括号 |
| `vit` / `vat` | HTML/XML 标签内 / 含标签 |

小技巧：重复 `i(` 或 `a(` 可以逐层向外扩大到外层括号，如 `va(a(`。

## 4. 对选区的常用操作

| 按键 | 说明 |
| --- | --- |
| `y` | 复制 |
| `d` / `x` | 删除（剪切） |
| `c` | 删除并进入插入模式 |
| `p` / `P` | 用寄存器内容替换选区 |
| `>` / `<` | 增加 / 减少缩进 |
| `=` | 自动格式化缩进 |
| `~` / `u` / `U` | 切换大小写 / 转小写 / 转大写 |
| `J` | 合并选中行 |
| `r{c}` | 把选区每个字符替换为 `c` |
| `:` | 对选区执行命令（自动填入 `:'<,'>`） |
| `"+y` | 复制到系统剪贴板 |
| `Ctrl-a` / `Ctrl-x` | 选中数字加 1 / 减 1 |
| `g Ctrl-a` | 选中多行数字递增（生成序列） |

## 5. 块可视模式（`Ctrl-v`）技巧

| 操作 | 说明 |
| --- | --- |
| `Ctrl-v` → `j` 若干 → `I` → 输入 → `Esc` | 在多行同一列前插入文本 |
| `Ctrl-v` → `j` 若干 → `$` → `A` → 输入 → `Esc` | 在多行行尾追加文本 |
| `Ctrl-v` → 选块 → `c` → 输入 → `Esc` | 替换多行的同一列块 |
| `Ctrl-v` → 选块 → `d` | 删除一列矩形区域 |

## 6. 选区相关的 Ex 命令

| 命令 | 说明 |
| --- | --- |
| `:'<,'>s/old/new/g` | 只在选区内替换 |
| `:'<,'>sort` | 对选中行排序 |
| `:'<,'>normal A;` | 对选中每行执行普通模式命令（如行尾加 `;`） |
| `:'<,'>w file.txt` | 把选中行写入文件 |
| `:'<,'>!cmd` | 用外部命令过滤选区 |

## 7. 标记

| 按键 | 说明 |
| --- | --- |
| `` `< `` / `` `> `` | 跳到上次选区的起点 / 终点 |
| `ma` → 移动 → `` v`a `` | 从当前位置选到标记 `a` |
