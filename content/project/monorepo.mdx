## ⚡ 核心技术选型

|模块|推荐方案|说明|
|:---|:---|:---|
|后端框架|NestJS|企业级架构，模块化、依赖注入、原生支持微服务|
|移动端|Expo + React Native|跨平台 iOS/Android，一套代码多端运行|

|Web UI|Tailwind + shadcn/ui|现代 CSS 框架 + 高度自由定制的组件库|
|Admin UI|Arco Design|字节开源企业级 UI，内置完整 Admin 生态|

## 🔍 核心模块详解

###  1️⃣ ORM：为什么首推 Drizzle？

Drizzle 示例代码：

```ts
// schema.ts - Schema 即类型
import { pgTable, serial, text, integer } from'drizzle-orm/pg-core';

exportconst users = pgTable('users', {
id: serial('id').primaryKey(),
name: text('name').notNull(),
email: text('email').notNull().unique(),
});

// 类型自动生成
type User = typeof users.$inferSelect;
```

### 2️⃣ Auth 认证：Better Auth 集成

Better Auth 已提供对 NestJS 的官方支持，集成开箱即用：

```bash
npm install better-auth nestjs-better-auth
```

代码示例：


```ts

app.use(bodyParser.json()); // 禁用默认 body parser

// app.module.ts

// 路由保护

// session.user 包含当前登录用户信息
  }
}
```
